隐私政策

生效及更新日期：2026 年 9 月 29 日

本政策由 Tablefolk App 开发者提供，说明 Tablefolk iPhone App、本信息网站及支持反馈的数据处理。公开网站和反馈仓库由 GitHub 账户 s045pd 维护。

先说重点：Tablefolk 不要求创建账号，不记录你对题目的回答，不设置广告或行为分析 SDK。收藏与偏好保存在本机。购买由 Apple 处理；网站访问和公开反馈使用 GitHub，客服邮件使用 Gmail。这些服务分别按其政策处理你主动提供的资料。

1. App 在本机保存什么

  • 收藏的玩法和题目编号，用于显示收藏和优先排序。
  • 语言选择、教学演示速度和成人年龄确认结果，用于保留你的设置。年龄确认只保存是否确认，不要求出生日期或身份证。
  • 成人话题开关是本次使用中的选择，默认关闭；购买不会自动开启。

这些资料通过系统的本机偏好存储保存，不上传到 Tablefolk 服务器。我们不保存题目回答、聊天记录或录音，也不要求通讯录、精确位置、照片、相机或麦克风权限。

2. 购买与恢复购买

购买和恢复购买使用 Apple App Store 与 StoreKit。App 在设备上处理商品信息及经 Apple 验证的交易资料，例如商品编号、交易编号、购买类型、有效期（如适用）及退款或撤销状态，以判断付费内容是否可用。这些资料不上传到我们自有的服务器。

我们不接收你的银行卡资料、Apple 账户密码或支付验证信息。Apple 按其隐私政策处理支付、账户和商店服务。系统备份、诊断和商店记录也受 Apple 的政策及你的系统设置影响，不等同于 App 向 Tablefolk 上传收藏或回答。

3. 本网站与客服反馈

本网站使用 GitHub Pages 托管，没有接入额外的统计、广告脚本、第三方字体或追踪 Cookie。根据 GitHub Pages 文档，GitHub 会为安全目的记录和保存访客的 IP 地址，即使访客没有登录。

支持页的反馈入口使用 GitHub Issues，需要 GitHub 账号。你主动提交的用户名、文字和附件会在公开仓库中显示，Tablefolk 开发者和其他人都可能看到。我们仅为排查问题、回复反馈和维护产品使用这些信息，不用于广告画像。

请勿公开提交密码、Apple 账户、完整收据、支付资料、个人回答、私密聊天或未打码的截图。访问和反馈由 GitHub 按其隐私声明处理，可能在你所在地区以外处理或存储。我们不控制 GitHub 的基础设施或平台保存期限。

你也可以向客服邮箱 s045pd.x@gmail.com 发送邮件，不需要 GitHub 账号。我们会看到你主动发送的发件地址、正文和附件，只用于回复、排查问题及处理隐私或权利请求，不用于广告营销。客服邮件不会像 GitHub Issues 一样公开发布。

客服邮箱使用 Gmail，邮件由 Google 按其隐私政策处理，可能在你所在地区以外处理或存储。请只发送解决问题所需的资料，不要发送密码、支付资料、完整收据或无关的私密记录。

4. 保存期限与删除

本机收藏和偏好会保留到你取消收藏、修改设置、重置本地数据或卸载 App。可在 App「设置」中选择「重置本地数据」，清除收藏、年龄确认、语言与演示偏好。系统备份或设备恢复可能再次带回旧资料，备份由你通过 Apple 的系统设置管理。

重置不会删除 Apple 保存的购买记录、取消订阅或让有效购买失效。订阅（如提供）需要在 Apple 的订阅设置中单独管理。

公开反馈会保留供问题处理和历史追踪，直到由作者或仓库维护者修改、删除，或按 GitHub 的平台规则处理。若需要协助更正或删除你提交的反馈，可通过支持页联系维护者，说明具体反馈链接，不要再次公开敏感资料。GitHub 的日志、缓存及备份删除由 GitHub 按其政策处理。

客服邮件在处理反馈及必要后续跟进期间保存，之后删除不再需要的个人资料；依法需要保留的信息除外。如需更正或删除你发来的邮件，可向同一客服邮箱提出请求，说明原邮件的时间或主题，无需再次发送敏感资料。Google 的平台日志及备份按其政策处理。

5. 你的选择与权利

你可以查看或移除收藏、修改偏好、关闭成人话题，不提交反馈，也不访问外部网站。无需授权跟踪即可使用本机内容。购买不是同意开启成人话题。

如适用法律赋予你查询、更正、删除或其他个人信息权利，可通过支持页提出请求。对仅存在于你本机的资料，我们没有远程读取能力；可通过 App 的本机操作处理。Apple 和 GitHub 各自处理的数据，请使用相应平台的隐私权利入口。

6. 成人内容与政策变更

Tablefolk 面向成年人，成人话题需要另外选择开启。我们不为收集未成年人资料设计功能。如果你认为公开反馈包含未成年人的个人信息，请联系维护者协助处理。

如果 App 的数据处理方式变化，我们会更新本政策和日期，并在法律要求时另行提示或获取同意。

7. 联系我们

客服邮箱：s045pd.x@gmail.com。可通过邮件联系 Tablefolk 开发者，或使用帮助与支持页的 GitHub 公开反馈入口。涉及个人信息或隐私权利请求时，请使用邮件，不要公开提交。
