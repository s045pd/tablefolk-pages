在 GitHub 提交反馈

需要登录 GitHub 账号。反馈由维护这个网站的 Tablefolk 开发者查看。请描述遇到的问题，并提供 App 版本、iPhone 型号、iOS 版本和能重现问题的步骤；如涉及某个玩法或题目，提供其名称或编号即可。

GitHub 反馈是公开的，不是私密客服工单。不要提交密码、Apple 账户、完整购买收据、支付资料、个人回答或私密聊天。截图请先打码。涉及个人信息或隐私权利请求，请改用上面的客服邮箱。

已购买，但付费内容没有解锁

  1. 检查 iPhone 的 App Store 是否使用购买时的 Apple 账户，并保持联网。
  2. 打开 Tablefolk「设置」，选择「恢复购买」，等待显示结果。
  3. 如果 Apple 显示交易待处理，等待 Apple 确认后再检查。不要为同一权益反复购买。
  4. 仍有问题时给客服发邮件，说明状态和操作步骤，不要发送完整收据。

购买只解锁内容，不自动打开成人话题。成年用户还需在「设置」中另外选择「特辣题库」。

如何取消订阅或申请退款

如果你购买了订阅，可在 iPhone「设置 → Apple 账户 → 订阅」中管理。删掉 App 或重置数据不会取消订阅。购买买断也不会自动取消已有订阅。

查看 Apple 取消订阅说明。退款由 Apple 处理，请按 Apple 申请退款说明操作。可用购买方案以 App 实际显示为准。

如何删除本机数据

打开 Tablefolk「设置 → 重置本地数据」。这会清除本机收藏、年龄确认、语言与演示偏好，并关闭成人话题。有效购买会保留；购买记录和订阅需通过 Apple 管理。系统备份可能保留旧资料，备份请在系统设置中另行管理。

离线、语言与题目顺序

玩法与题库随 App 保存，可离线浏览。购买、恢复购买和这些网站页面需要联网。可在「设置 → 语言」切换中文或英文。每次进入题库会重新随机排序，收藏的题优先显示。

题目或翻译需要修改

如果某句话别扭、规则不清楚或内容不适合，欢迎提供名称或编号、当前语言和修改建议。不要上传付费题库全集。每个人都可以跳过题目，不必回答或解释。

政策与条款

隐私政策说明本机资料、Apple 购买和 GitHub 访问数据；使用条款说明玩法及付费权益。
